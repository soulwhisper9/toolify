Frequently asked questions

What is Markdown?
Markdown is a lightweight text format that uses simple symbols to add formatting. For example, **bold** and *italic*. Widely used on GitHub, Reddit, Discord, and many blogging platforms.
What flavor of Markdown is supported?
GitHub Flavored Markdown (GFM). Includes tables, code blocks with syntax hints, strikethrough, task lists, and auto-linked URLs.
Can I paste HTML into the HTML section of my site?
Yes. The output is clean semantic HTML you can paste anywhere — WordPress HTML block, static site, or an email newsletter template.
Is my content uploaded?
No. All conversion runs in your browser using the marked.js library. Your text never leaves your device.
