Frequently asked questions

What is the difference between AND, OR and XOR?
AND gives 1 only when both bits are 1. OR gives 1 when at least one bit is 1. XOR gives 1 when exactly one bit is 1, so it flags differences. XOR is widely used in checksums and simple encryption.
What do the shift operators do?
A left shift moves every bit one place left and pads with zero, which doubles the value each time. A right shift halves it and discards the rightmost bit. Shifts are much faster than multiplication on most processors.
Why is NOT giving a negative number?
JavaScript uses 32-bit two's complement for bitwise operations, so NOT of a positive number produces a negative result. NOT 5 becomes −6, following the rule that ~x equals −(x + 1).
How is this different from a base converter?
A base converter only changes representation. This tool performs actual arithmetic and logic between two binary values and shows the result across every common base.
