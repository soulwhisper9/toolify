Frequently asked questions

Why does programming use hexadecimal so much?
One hex digit maps exactly to four binary bits, so a byte is always two hex digits. That makes memory addresses, colour codes and binary data far easier to read than long strings of ones and zeros.
What do the letters A to F mean?
Hexadecimal is base 16, so it needs six extra symbols beyond 0–9. A is 10, B is 11, C is 12, D is 13, E is 14 and F is 15. FF is therefore 255, the largest value a single byte can hold.
Why do colour codes use hex?
A colour like #7B61FF packs three bytes into six digits: 7B is red, 61 is green and FF is blue, each ranging from 00 to FF. Enter any six-digit value above and a live colour swatch appears.
Do I need the 0x prefix?
No. The 0x prefix marks hex in languages like C and JavaScript, but this calculator accepts values with or without it, and is not case sensitive.
