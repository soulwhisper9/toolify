Tips for reliable scanning
  • Test the code with your own phone before printing or sharing it.
  • Keep High error correction so the code still scans if partly damaged.
  • Print at 2cm by 2cm minimum. Larger is more reliable.
  • Avoid curved or reflective surfaces.
  • Add a short line of text nearby such as Scan for menu.
