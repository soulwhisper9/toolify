Frequently asked questions

Is my password uploaded anywhere?
No, absolutely not. All calculation happens inside your browser using JavaScript. Your password is never sent to any server, never stored, never logged.
How is strength calculated?
We use entropy in bits (log2 of possible combinations). Longer passwords with diverse character sets have higher entropy. We also check against common passwords and repeated patterns.
What is "crack time"?
Estimated time to crack via offline brute force assuming a modern GPU doing 100 billion guesses per second. Real attacks are usually slower (rate-limited), so this is a worst-case number.
Should I use this to test my real passwords?
Yes, safely. But general advice: use a password manager (Bitwarden, 1Password, KeePass) to generate and store unique 20+ character passwords for every account.
