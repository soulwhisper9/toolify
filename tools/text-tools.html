Frequently asked questions

How does duplicate removal work?
We compare each line and keep only the first occurrence of each unique line. Options let you ignore case and trim whitespace before comparing.
Sort alphabetically vs numerically?
Alphabetical sorts like a dictionary. Numeric mode sorts "2" before "10" (correct number order) instead of "10" before "2" (alphabetical order).
Does find & replace support regex?
Yes. Toggle the "Regex" option to use regular expressions. Otherwise it does plain text replacement.
Is my text uploaded?
No. All operations run in your browser.
