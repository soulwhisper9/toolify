Frequently asked questions

Why is matrix multiplication not commutative?
A × B and B × A usually give different results because each entry comes from a row of the first matrix meeting a column of the second. Swapping the order changes which numbers pair up. Order matters in linear algebra.
What does the determinant tell me?
It measures how the matrix scales area or volume. A determinant of zero means the matrix is singular, has no inverse, and collapses space into a lower dimension. A negative value means orientation is flipped.
When does an inverse not exist?
Whenever the determinant is zero. This happens if one row is a multiple of another, or if rows are linearly dependent. This calculator will tell you when the matrix is singular.
What is a transpose used for?
Transposing flips rows into columns. It appears throughout statistics, computer graphics and machine learning, notably in the normal equation for least-squares regression.
