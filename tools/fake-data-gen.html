Frequently asked questions

Is this data real?
No, everything is randomly generated from name lists and patterns. Not real people, phones, or addresses. Safe for testing and development only.
Can I use for production?
No, it's test data only. For production seed data, use realistic patterns but never publish generated identities as if they were real users.
How random is it?
Uses JavaScript's built-in Math.random which is pseudo-random. Good enough for tests, not cryptographically secure.
Is my data uploaded?
No. All generation runs in your browser.
